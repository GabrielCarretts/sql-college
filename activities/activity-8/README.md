# Activity 8 — Table design and data changes

Create tables and foreign keys, change column definitions, insert sample rows, update salaries, and delete project assignments.

## Running the script

Open [solutions.sql](solutions.sql) in MySQL Workbench on a disposable local server. The file includes its own database setup. **Warning:** Running the setup drops and recreates `atividade_8_db`, deleting any existing data in that exercise database. Use a disposable local database, then select and execute one exercise at a time.
