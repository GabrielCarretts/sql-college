# Activity 13 — Subqueries

## Learning objectives

Practice using nested queries to compare employees and identify groups from aggregate results.

## Exercises

1. Find employees earning above the average salary.
2. Find employees belonging to the most common gender.
3. Find employees working in the largest department.
4. Find employees assigned to the project with the most participants.
5. Find the department of the highest-paid employee.
6. Find projects involving the lowest-paid employee.

## Concepts practiced

SELECT, WHERE, subqueries, aggregate functions, and comparisons against query results.

## Running the script

Open [solutions.sql](solutions.sql) in MySQL Workbench on a disposable local server. The file includes its own database setup. Read the opening statements before running them, then select and execute one exercise at a time. The setup drops and recreates the database named in the script.
