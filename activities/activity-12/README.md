# Activity 12 — Aggregation and JOINs

## Learning objectives

Practice summarizing employee data and relating employees, departments, and projects.

## Exercises

1. Count employees grouped by gender.
2. Count employees grouped by department.
3. Count employees assigned to each project, sorted by quantity.
4. Find the department with the highest total salaries.
5. Find the project with the highest average employee salary.
6. Find projects containing only female employees.

## Concepts practiced

SELECT, WHERE, JOIN, GROUP BY, HAVING, COUNT, SUM, AVG, and ORDER BY.
