# Activity 9 — Filtering and sorting

Select columns, filter employee names and dates, and order results by salary.

## Running the script

Open [solutions.sql](solutions.sql) in MySQL Workbench on a disposable local server. The file includes its own database setup. **Warning:** Running the setup drops and recreates `atividade9`, deleting any existing data in that exercise database. Use a disposable local database, then select and execute one exercise at a time.
